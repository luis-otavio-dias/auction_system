# Imagens do acervo de demonstração

Reproduções em domínio público das obras usadas pelo `seed_demo`, obtidas do
Wikimedia Commons como alternativa às URLs da Art Institute of Chicago (que
respondem com desafio do Cloudflare neste ambiente):

- `grande-jatte.jpg` — *A Sunday on La Grande Jatte*, Georges Seurat.
- `american-gothic.jpg` — *American Gothic*, Grant Wood.
- `nighthawks.jpg` — *Nighthawks*, Edward Hopper.
- `the-bedroom.jpg` — *The Bedroom*, Vincent van Gogh.

Os arquivos `*-thumb.jpg` são reduções locais usadas nas listas do catálogo.
